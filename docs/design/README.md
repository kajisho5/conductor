## メニュー構成

iPad（regular 幅）はサイドバー、iPhone（compact 幅）はタブバー。できることは同じ。

| iPad サイドバー | iPhone | 中身 |
|---|---|---|
| ボード（配下にページ一覧） | ボード タブ | ボタン盤。運用 / 編集 の切替 |
| オートメーション | 自動化 タブ | 時刻・状態の変化・起動・接続の変化で動作を実行 |
| 変数 | 変数 タブ | 機器から読んだ値、自分で作る変数 |
| 機器 | 機器 タブ | 接続の追加・設定・状態・診断 |
| 外部コントローラ | 設定 > 外部コントローラ | MIDI パッド等をボタン盤として使う（後のマイルストーン） |
| ログ | 設定 > ログ | 通信・警告のログ |
| バックアップ | 設定 > バックアップと読み込み | ショーファイルの書き出し・読み込み |
| 設定 | 設定 タブ | スリープ防止、ロック、触覚、既定グリッド |

## 参考ソフトとの違い（そのまま似せないために変えた点）

| 参考ソフトの考え方 | conductor |
|---|---|
| Web 管理画面と物理ボタン盤が別 | 1 台の中で「運用 / 編集」を切替。編集はその場でインスペクタ |
| 用語: Connections / Buttons / Triggers / Variables / Surfaces | 用語: 機器 / ボード / オートメーション / 変数 / 外部コントローラ |
| 変数の書式 `$(接続名:変数名)` | `{機器名.変数名}`、書式は `{…|hh:mm:ss}` |
| 正方形の LCD キー風ボタン、上に小さな位置番号 | 角丸ボタン、上に小見出し（PGM / ON など）、下にステップの点、未接続は暗転＋⚠ |
| ページ番号を上下ボタンで送る | ページ名のピル列＋左右スワイプ、iPad はサイドバーにページ一覧 |
| 押す / 離す | 押した時 / 離した時 / 長押し（0.8 秒）の 3 つ。グループごとに「順番に実行 / 同時に実行」 |
| — | 本番表示（ロック、時計、接続状況だけ） |
| — | 状態ドットは色＋形（塗り / 半分 / 輪郭）で色覚に依存しない |

名前・ロゴ・画像は参考ソフトのものを一切使わない。メーカー名は機種名の文字表記だけ（ロゴなし）。

## 確認してほしい決め事

1. **グリッドの既定サイズ 8 列 × 6 行**（ページごとに 4–12 列 × 3–8 行で変更可）
2. **iPhone 縦は 4 列ずつ表示**（1–4 列 / 5–8 列を左右スワイプ）。そのためページの切替はタイトルのメニュー／シートから。iPhone 横は 8 列全部＋縦スクロール
3. **編集は同じ画面で「運用 / 編集」切替**、iPad は編集時にサイドバーを畳んでインスペクタを出す
4. **長押しを 3 つ目の操作グループとして持つ**（0.8 秒、ボタンごとに変更可）
5. 表示はシステムのライト/ダークに従う（アプリ独自の外観設定は作らない＝HIG）。現場向けに既定のボタン色は暗め
